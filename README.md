# 班級經營系統 — 最高行政管理端 (Super Admin Portal)

> **多校租戶授權 · 學校管理帳密統一派發 · 多校穿透巡查 · 全系統公告**  
> 由高雄市立七賢國中 107 王禹硯（國一生）獨立編程研發設計，專供系統最高決策管理員統籌管理全國各級合作學校之智慧校園中樞。

---

## 📌 系統全景與權限職能

本系統為四層級架構之最高層級（Super Admin），具備最高安全控管規格：

1. **👑 Google 帳號授權驗證**：
   - 僅限授權 Google 帳號（`ianw.solar@gmail.com`）登入。
   - 嚴格阻絕任何未經授權之外部訪問。

2. **🏫 學校租戶授權與管理帳號派發中樞**：
   - 統一建立與維護各級中小學之獨立租戶代碼、學校名稱、管理員帳號與預設安全密碼。
   - 支援全校管理帳號一鍵批量產生器與一鍵匯出清冊 CSV / Excel。
   - 控管各校之授權班級數上限、授權效期與在籍學生規模。

3. **🔍 多校行政穿透抽查中樞**：
   - 即時穿透檢視各校 08:00 晨間到校率、學事清冊與行政抽查核章進度。

4. **📢 全系統全域維護與公告**：
   - 發布全系統維護公告與版本升級通知，即時連線推播至各校管理端、教師端與家長端。

5. **🛡️ 系統安全稽核日誌 (Audit Trail)**：
   - 嚴格記錄所有學校管理帳號派發、密碼重置、授權變更與登入歷程。

## 🔒 資訊安全規範

- **全域隔離**：最高管理端與學校管理端、教師端、家長端採獨立倉庫與獨立資料命名空間部署，杜絕跨權限提權風險。
- **無 Emoji 圖示規範**：全站介面統一使用 FontAwesome 向量圖示素材庫，確保行政系統之莊重專業。
